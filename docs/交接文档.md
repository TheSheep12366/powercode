## 一、项目概述

**PowerCode** 是部署于 Linux 服务器的网页版多人在线代码协作平台，核心能力：

- **管理面板**：用户管理、权限组（角色模板）、目录共享、权限矩阵、审计日志、公告/全员计划
- **工作区**：文件树 + CodeMirror 6 多标签协作编辑器（Yjs 实时同步、远程光标/选区）+ 在线列表 + 文件操作（新建/重命名/删除/上传/下载/zip）+ 保存体系
- **仪表盘**：可自定义卡片（12 种：通讯录/项目详情/贡献图/代码统计/最近动态/日历/公告/倒数日/TODO/用户管理/快捷创建/AI 预留），支持增删与拖拽排序，布局按用户持久化
- **身份体系**：登录/单点登录强制（顶号踢下线）、头像、在线状态（"正在使用即在线"）、用户主页模态、通讯录（可见性可切换）
- 规划文档（原始需求 + 功能清单 P0/P1/P2 + 优先级定义）：`docs/技术栈与功能清单.md`

## 七、关键架构决策（为什么这么做）

1. **权限单一真源**：`packages/shared` 的 `computeEffectivePermission`——优先级 = 管理员 > 用户级条目(含 deny) > 权限组授予 > 组级条目(deny>rw>ro) > none。前端矩阵渲染与后端 `lib/permissions.ts` 鉴权共用同一函数。
2. **协作层鉴权**：Hocuspocus `onAuthenticate` 解析 upgrade 请求 Cookie → 会话 → `effectivePermissionFor`；`none/deny` 拒绝、`ro` 设 `connectionConfig.readOnly`（服务端拒写）。
3. **终端走 SSH**（M7 方案）：ssh2 连本机 sshd 以用户系统账号执行，权限边界由 OS 保证；平台非 root 运行。
4. **文档写盘**：Yjs 文档防抖 1s 原子写（tmp+rename）；强制保存走 stateless 消息（client `sendStateless` → 服务端 `onStateless` 写盘回执 `stored`）。
5. **自动换行全局同步**：偏好存文档内 `Y.Map('prefs')`，一人切换全员生效（会话级，不落盘）。

## 八、踩坑记录（全部真实踩过，勿重蹈）

### 环境类
1. **宝塔 iptables/ip6tables INPUT 均为 DROP 策略**——LAN 不通的真正元凶（Windows 防火墙不是）。放行：`iptables -I INPUT 1 -p tcp --dport 3100 -j ACCEPT`（ip6tables 同理）。**规则存内存，重启即丢**→ 宝塔"安全→系统防火墙"持久化。
2. **宝塔全局 npm 缓存 `/www/server/nodejs/cache` 为 root 专属**——非 root 装依赖 EACCES → 回退 node-gyp（无 python3）直接失败。命令行安装必须 `npm_config_cache=$HOME/.npm/cache`；本项目 .npmrc 已配 npmmirror + better-sqlite3 二进制镜像。
3. **系统 node 是 v20**——better-sqlite3 等原生模块 ABI 与 v22 不匹配，构建/运行一律用宝塔 v22 路径。
4. **宝塔添加/启动 Node 项目会对项目目录 chown 成 www:www**，导致开发用户写不进。恢复：`docker run --rm -v /www/wwwroot/powercode:/p redis:latest chown -R 1000:1000 /p`（用户在 docker 组可提权）。**勿在宝塔启动本项目**。
5. LAN IPv6 访问需 ip6tables 放行（v6 链同样 DROP）；公网 IPv6 还取决于路由器防火墙。

### 组件类（fuxsto-design 0.1.1）
6. **主入口 `fuxsto-design` 与 dialog 的命名导出 `{ Dialog }` 都是命令式函数**（Dialog(options) 直接弹窗），当组件写进模板会渲染成 `[object Object]`。**组件一律子路径默认导出**：`import DialogDefault from 'fuxsto-design/dialog'`；Message 是命名导出 `{ Message }`（函数式 API）；checkbox-group/radio-group 是独立子路径。
7. `ViewPlugin.fromClass` **必须传类**（内部 `new`），传对象字面量 → "e is not a constructor" 且插件静默崩溃（编辑器看着正常但功能丢失）。
8. Card/Input/Select 等组件内部自带 `w-full`，外部定宽类会被 tailwind-merge 吃掉——外层包定宽 div 或用 Tailwind v4 important 后缀（`w-56!`）。
9. y-codemirror.next 0.3.6 远程光标：awareness.cursor 必须是 **RelativePosition**（`Y.createRelativePositionFromTypeIndex`），裸数字不渲染；名字标签 hover 才显示。自动换行开关需文档 `Y.Map('prefs')` 共享。
10. archiver 8 是原生 ESM 类导出（`new ZipArchive()`），无默认函数；multer 必须用 2.x（1.x 有漏洞）。
11. pnpm 10 会拦截依赖构建脚本——`pnpm-workspace.yaml` 已配 `onlyBuiltDependencies: [better-sqlite3, esbuild]`。
12. **pnpm 版本钉死 10.34.5**（packageManager 字段）：pnpm 11 会崩（verifyDepsBeforeRun + 配置位置变更）。

### 代码类
13. **Hocuspocus v4 手动挂接**三件套：① 用 Web 标准 Request；② handleConnection 后必须手动转发 `message → conn.handleMessage(new Uint8Array(data))` 与 `close → conn.handleClose`；③ readOnly 在 `connectionConfig` 上设。
14. **presence 按会话粒度清扫**：按用户清扫会让被顶替设备的 socket 永远踢不掉（同用户新设备会话有效）。
15. **前端 API 路径与后端挂载逐一核对**（曾因 meta 路径差一层导致 Promise.all 静默 404、用户勾选框全空）。加载失败别静默吞，至少 console.error。
16. **pkill -f 会匹配自身 shell 命令行**导致误杀自己；停止服务一律按端口找 PID：`ss -tlnp | grep :3100 | grep -oP 'pid=\K\d+'`。
17. **无头 Edge 用完必须清理** `/tmp/edge-profile`、`/tmp/edge-shots`、`/tmp/edge-test`（用户明确叮嘱）。
18. 测试脚本断言避免绝对数量（其他真实在线用户会污染计数），用成员判断。
19. 同浏览器双标签登不同账号会互相覆盖 Cookie（浏览器机制），测多账号用两台设备/两个浏览器。

```bash

# 前端单独开发
pnpm dev:web         # Vite 5173，/api 代理 3100

# Node22 内置 WebSocket 直连 CDP：Page.navigate/Runtime.evaluate/Page.captureScreenshot
```

## 十、注意事项（叮嘱）

1. **别在宝塔面板操作本项目**（chown + 端口冲突双重风险）；宝塔只当 Nginx/防火墙管理器用。
2. 服务重启后**记得重打防火墙规则**（或宝塔防火墙持久化 3100）。
3. `.env` 含初始管理员密码，生产务必改密并启用 HTTPS（COOKIE_SECURE=true）。
4. data/ 目录是唯一状态（SQLite + 头像），**备份 = 备份 data/ + 共享工作区**。
5. 改前端后只需 `pnpm --filter @powercode/web build`（后端静态托管直接生效）；改后端必须重启进程。
6. 前端接入新组件时**先读本文第八节第 6-10 条**。
7. 编辑器打开保护阈值为 2MB（MAX_EDIT_SIZE，collab/hocuspocus.ts 与 routes/my-fs.ts 各有一处）。
